# dhk-predicts-features

`app/` is the runnable DHK-Predicts app with six features (streak, admin password reset, SMS-code login, sponsor line, audit CSV, due-soon tag). Quickstart and a feature-to-files table are in `app/README.md`. It was built from the `ccr-e3d32d8f-y7yw8y` branch of DataBD1/DHK-Predicts, which includes the SMS-code login screen. The earlier patch file was retired because it was missing that screen.
